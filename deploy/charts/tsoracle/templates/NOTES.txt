TLS is enabled. The Secret {{ .Values.tls.secretName | quote }} must contain:
  tls.crt  — server certificate (or chain)
  tls.key  — server private key
  ca.crt   — cluster-dedicated CA certificate used to sign peer and (when
             clientMtls=true) client certificates

Peer connections between replicas require a CA shared across all nodes.
Do not reuse a public CA here — provision a dedicated internal CA.
